# MERN News Portal

A full-stack news portal built with the MERN stack. Users can browse news, create accounts, publish news, and manage their own published articles.

## Live Website

https://mern-news-portal-six.vercel.app/

## Features

- Responsive homepage
- Latest news section
- All news page
- Search and category filtering
- News details page
- User registration and login
- JWT authentication
- User profile management
- Create and publish news
- Edit own news
- Delete own news
- Contact page
- Mobile responsive design

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- Axios
- Zustand
- React Router
- Lucide React

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt
- CORS
